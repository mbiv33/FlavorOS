# Logistics and Pre-Event Protocol Runbook Template

## Purpose

Describe how the pre-event readiness workflow should run and what artifacts it produces.

## Trigger

- Upcoming event detected in calendar
- Pre-event planning session
- Manual readiness check request

## Steps

1. Authorize calendar access
2. Extract event metadata and participants
3. Enrich participants with relationship context
4. Build event readiness checklist
5. Output readiness artifacts for review

## Artifacts

- `event_readiness.md`
- event logistics metadata
- pre-event communication plan

## Quality Checks

- Event participants are linked to relationships
- Readiness checklist covers logistics and agenda preparation
- Output file is readable and actionable
