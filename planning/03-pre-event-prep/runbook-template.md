# Pre-Event Prep Runbook Template

## Purpose

Capture the process for preparing people, materials, and logistics ahead of upcoming events.

## Trigger

- Upcoming event detected in calendar
- Event prep session requested
- Pre-event readiness review

## Steps

1. Extract event details and objectives
2. Review participant relationship context
3. Confirm logistics and material readiness
4. Build a prep plan with action items
5. Output `pre_event_prep.md` for review

## Artifacts

- `pre_event_prep.md`
- event readiness checklist
- participant prep notes

## Quality Checks

- Events have clear objectives and logistics details
- Prep items link to relationship and logistics context
- Output is actionable and ready for execution

## Handoff Notes

- Keep this runbook aligned with the logistics and relationship discovery features
- Use the planning integration directory for experiments before moving to live code
